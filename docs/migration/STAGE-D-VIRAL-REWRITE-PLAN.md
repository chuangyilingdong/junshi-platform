# 爆款复刻改写方案验收

日期：2026-11-02

## 问题

原流程在确认原文后直接进入“改写文案”：

- 没有让用户选择改写逻辑或强度
- 蓝图在第一个版本生成后才附带产生，无法先审阅
- 提示词只要求“学习传播机制”，没有强制建立“原机制 → 本账号业务”的映射
- 模型容易直接回到账号行业模板，写出与原文推理链无关的内容

## 新流程

```text
确认原文
→ 拆解原文机制
→ 生成 3 套改写方案
→ 用户选择其中一套
→ 按同一方案生成 3 个版本
→ 选版进入定稿
```

## 改写方案包含

- 原文真正回答的问题
- 开场机制
- 信息推进链
- 转折与收束
- 必须替换的原行业事实
- 可迁移机制
- 迁移到本账号业务的具体桥梁（`targetBridge`）
- 改写后要证明的核心判断
- 4–8 个段落节拍
- 可使用的账号证据
- 最容易写偏的地方

## 版本生成约束

- 三个版本必须共用同一个已选方案
- 只改变开场、语气、句式和节奏，不能换主题或逻辑
- 必须覆盖方案的主要 `beats`
- 标题必须体现方案 `thesis`
- 不得绕过业务桥梁，直接写账号行业常识
- 不得复用原爆款的人物、数字、案例、原句或一一对应镜头

## UI

- 新增“选改写方案”步骤
- 方案卡显示“保留机制 / 迁移到本账号 / 要证明 / 段落节拍”
- 生成版本时显示“当前改写方案 + 业务桥梁”
- 支持换一批方案、重选方案
- 方案失败有单独重试入口，不再直接跳去写正文
